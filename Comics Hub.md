# Comics Hub

Start here. The book database is the `Books/` folder (one note per book, with properties). The dashboards below read those notes, so you only update a book's note and everything else follows. `Epics.xlsx` is kept as a frozen backup of the old sheet.

## Dashboards (Bases)
- [[Cart Planner]] - runway per line, candidates by purpose, current cart (start here each month)
- [[Cart.base|Cart]] - books assigned to a monthly cart, with the total
- [[Reading Queue.base|Reading Queue]] - owned/covered and unread, plus "Next up"
- [[Buy List.base|Buy List]] - wanted, hard to find, planned
- [[Incoming and Pre-orders.base|Incoming and Pre-orders]] - by budget (monthly vs quarterly)
- [[Collection.base|Collection]] - everything, with a view per line
- [[Spending.base|Spending]] - paid so far, by store
- [[Ratings.base|Ratings]] and [[Ratings Overview]] - Goodreads reader ratings per Epic, compared with the old ChatGPT/Gemini tiers
- [[To Verify.base|To Verify]] - books whose info I haven't confirmed
